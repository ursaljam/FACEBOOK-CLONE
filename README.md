# FACEBOOK-CLONE
This Facebook Clone is a basic social media application built using PHP and MySQL, designed to replicate core functionalities of Facebook, such as user authentication and post creation. The project serves as an educational tool to understand full-stack web development with backend and frontend integration.

## Features
- **User Registration & Authentication**: Users can create accounts and log in using their credentials.
- **Post Creation**: Once logged in, users can create text posts and see them displayed in reverse chronological order.
- **Basic UI**: Simple interface for interacting with the app, styled with basic CSS.

## Technologies Used
- **Frontend**:
  - HTML5: For creating the structure of the web pages.
  - CSS3: For styling the user interface and making the application look modern and responsive.
  
- **Backend**:
  - PHP: Server-side scripting for handling user authentication, database interactions, and rendering dynamic content.
  - MySQL: A relational database used to store user information and posts.
  
- **Database**:
  - MySQL database with two main tables: `users` (for storing user information) and `posts` (for storing content posted by users).
